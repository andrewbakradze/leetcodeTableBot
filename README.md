# LeetCode Sync Journal

Бот сверяет решённые задачи LeetCode с вашей Google Таблицей **при запуске и затем раз в минуту**.
Для задачи, которой ещё нет в таблице, он показывает номер, название и ссылку, просит ввести **difficulties**, затем выбрать **Resolve**: **ДА**, **может быть** или **нет**.

Профиль по умолчанию: [1-andro1d-1](https://leetcode.com/u/1-andro1d-1/).

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python bot.py
```

Если окружение уже создано:

```bash
.venv/bin/python bot.py
```

В терминале бот открывается на отдельном полноэкранном экране, как Vim. Ввод заметок работает как обычно. При выходе через **Ctrl+C** восстанавливается предыдущий экран терминала; ошибки запуска выводятся после восстановления, чтобы их можно было прочитать. При перенаправлении вывода в файл полноэкранный режим отключается автоматически.

Существующий конфиг подключения сохраняется и мигрирует автоматически. Для нового поля **Resolve** нужно один раз заменить код на [apps-script/Code.gs](apps-script/Code.gs) и обновить развёртывание: **Начать развёртывание → Управление развёртываниями → Изменить (карандаш) → Новая версия → Развернуть**. Ссылка и токен остаются прежними. До обновления бот выдаёт понятную подсказку, не отправляя строку без Resolve.
При первом запуске бот спросит ссылку на таблицу, профиль LeetCode, URL Apps Script `/exec` и токен из `setup`.
Инструкция подключения Google — [apps-script/SETUP.md](apps-script/SETUP.md).

## Как это работает

1. Бот читает таблицу и историю принятых решений LeetCode.
2. Сопоставляет задачи по номеру или ссылке. Задачи, уже внесённые в таблицу, не предлагает повторно, даже если их решили ещё раз.
3. Для отсутствующих задач показывает карточку и предлагает написать difficulties.
4. После difficulties спрашивает **Resolve — нужно решить эту задачу повторно?**: `1 — ДА`, `2 — может быть`, `3 — нет`. Можно ввести номер варианта или ответ словами.
5. Сохраняет заметку и выбор Resolve локально, затем добавляет строку в Google Таблицу.
6. В фоновом потоке продолжает проверять профиль раз в 60 секунд, **даже пока вы вводите заметку**.

```text
╭────────── Принято на LeetCode • ещё нет в таблице ───────────╮
│ #1493  Longest Subarray of 1's After Deleting One Element   │
│ https://leetcode.com/problems/longest-subarray-of-1s-after-deleting-one-element/ │
╰─────────────────────────────────────────────────────────────╯
Какие difficulties возникли в этой задаче?
  │ Не сразу разобрался с удалением одного элемента.
  │ .
Resolve — нужно решить эту задачу повторно?
  1 — ДА
  2 — может быть
  3 — нет
Выберите 1, 2 или 3: 2
✓ №1493: difficulties и Resolve (может быть) сохранены.
```

**Точка на отдельной строке** завершает ввод. `/skip` сохраняет задачу без заметки. `/later` откладывает её до следующего запуска.
Выход — **Ctrl+C**. Незавершённый текст в текущем вводе при выходе не сохраняется; сама задача остаётся в очереди.
Если выйти на вопросе Resolve, завершённые difficulties уже сохранены: при следующем запуске останется выбрать Resolve. После ошибки отправки повторять уже выбранный ответ тоже не требуется.
Ручной ввод номеров, поиск по каталогу, редактирование старых заметок и прежние служебные команды удалены.

## Полная история и вход LeetCode

Без входа LeetCode предоставляет **последние 20 принятых отправок**. Они могут содержать повторы и не покрывать все решённые задачи.
Бот сравнивает количество уникальных видимых задач со счётчиком профиля и явно предупреждает, если сверка неполная. Ограничение нельзя устранить публичным каталогом задач: он не содержит ваш личный прогресс.

Для **всех** ранее решённых задач один раз подключите свою сессию:

```bash
.venv/bin/python bot.py --login
```

1. В Chrome войдите в нужный аккаунт на [leetcode.com](https://leetcode.com/).
2. Откройте инструменты разработчика: **F12** или **⌥⌘I** на Mac.
3. Перейдите в **Application → Storage → Cookies → https://leetcode.com** ([инструкция Chrome](https://developer.chrome.com/docs/devtools/application/cookies)).
4. Найдите cookies **LEETCODE_SESSION** и **csrftoken**. Скопируйте только значения столбца **Value** и вставьте их в соответствующие скрытые поля **терминала**.
5. Бот проверит, что сессия принадлежит профилю из конфига, и сохранит её локально. При следующих запусках повторять ввод не нужно, пока сессия действительна.

Эти значения дают доступ к вашему аккаунту; не присылайте их в чат. Бот передаёт их только HTTPS-адресу `https://leetcode.com/graphql/`, использует запросы чтения и не отправляет код решений. Перенаправления для запросов с cookies отключены.
Полный список загружается с пагинацией и фильтром Accepted. Если сессия истекла, повторите `--login`.
Для удаления локального входа удалите только `.leetcode-table-bot/leetcode_session.json`; останется ограниченный публичный режим.

GraphQL LeetCode не имеет гарантии стабильности. При HTTP 403, 429, сбоях сети или ошибках API бот сообщает об этом и повторяет проверку через минуту; ошибка не трактуется как отсутствие решённых задач.

## Таблица

Поддерживается ваш формат:

| problem number | problem name | my difficulties | link | Resolve |
| --- | --- | --- | --- | --- |
| 228 | Summary Ranges | Граничные случаи | https://leetcode.com/problems/summary-ranges/ | может быть |

Заголовки распознаются автоматически, включая `Resolve:` и другой порядок столбцов. Старый конфиг из четырёх столбцов автоматически дополняется по заголовкам таблицы при запуске. Пустой лист инициализируется пятью заголовками.
Если в столбце Resolve уже настроен выпадающий список, скрипт сохраняет его написание: например, `Нет` вместо `нет`.
Строки в таблице считаются уже учтёнными, даже если difficulties пустые. Бот их не изменяет.

## Очередь и настройки

- `config.json` — Google Таблица, Apps Script, профиль. Файл создаётся с правами только для владельца.
- `.leetcode-table-bot/pending_*.json` — задачи и завершённые заметки, ожидающие отправки. Очередь разделена по профилю, таблице и листу.
- `.leetcode-table-bot/leetcode_session.json` — сессия LeetCode, только если подключён полный режим.
- `.leetcode-table-bot/last_difficulties.json` — аварийная копия заметки, если задача появилась в таблице извне во время её ввода.

После ошибки записи бот перечитывает таблицу перед повторной отправкой: если Google успел сохранить строку, она не добавляется второй раз.
При тайм-ауте, обрыве соединения или HTTP 502/503/504 чтение Apps Script автоматически повторяется до трёх раз с паузами 2 и 4 секунды. Запрос записи сразу не повторяется: ответ мог потеряться после сохранения строки.
Если тайм-аут остаётся, проверьте интернет, VPN или прокси и доступ к `script.google.com` и `script.googleusercontent.com`. Завершённый `doPost` в журнале Apps Script ещё не подтверждает, что ответ дошёл до Python-бота.
Если вы закрыли программу с завершённой, но не отправленной заметкой, она восстановится из очереди при запуске.
Для изменения подключения или профиля: `python bot.py --setup`. Для отдельного конфига: `python bot.py --config /path/to/config.json`.
Google JSON-ключи, OAuth, gspread и открытый каталог задач больше не используются.
