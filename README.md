# LeetCode Table Bot

Консольная программа на Python для дневника решённых задач LeetCode в Google Таблицах.
Введите номер задачи, опишите сложности — название, номер, заметка и ссылка появятся в таблице.
Бот не требует логина LeetCode: факт решения отмечаете вы сами.

## Быстрый запуск

Нужен Python 3.10 или новее. В папке проекта:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python bot.py
```

В Windows вместо `source` используйте `.venv\Scripts\activate` (cmd) или `.venv\Scripts\Activate.ps1` (PowerShell).

При первом запуске программа спросит ссылку на Google Таблицу, адрес вашего Apps Script и его токен.
Ссылка и настройки сохранятся в `config.json` в текущей папке.
Подключение по умолчанию работает **без JSON-ключа и ручной настройки Google Cloud** — подготовьте скрипт по инструкции ниже.

Посмотреть интерфейс без ключей и сети:

```bash
python bot.py --demo
```

## Подключение к Google

### Без JSON-ключа: Apps Script

Откройте [пошаговую инструкцию](apps-script/SETUP.md). Вкратце: в вашей таблице откройте **Расширения → Apps Script**, вставьте [готовый код](apps-script/Code.gs), выполните `setup` и разверните веб-приложение с параметрами **Me / Anyone**.
После этого запустите:

```bash
.venv/bin/python bot.py --apps-script
```

Бот попросит обычную ссылку на таблицу, ссылку веб-приложения `/exec` и токен из журнала выполнения `setup`.
Токен защищает чтение и запись; хранится только в локальном конфиге, в интерфейсе не отображается.
Саму таблицу открывать для всех не требуется. При первом запуске скрипта Google попросит у вас разрешение на работу с таблицами.
Все основные возможности — распознавание столбцов, заметки, повторные решения и локальная копия — сохранены.

Если ранее бот уже просил JSON-ключ, используйте `--apps-script`: программа переключит сохранённый конфиг на новый способ и предложит ранее введённую ссылку на таблицу.

### Альтернатива: Google Sheets API с JSON-ключом

Старые конфиги продолжают работать. Для нового подключения с ключом используйте `python bot.py --google-api`.
Открытый доступ по ссылке позволяет читать таблицу в браузере. Для записи через Google Sheets API требуется авторизация.
Выберите **один** из двух вариантов ниже. Бот распознаёт тип JSON-ключа автоматически.

#### Вариант 1: сервисный аккаунт

Удобно для бота: не требуется вход через браузер, доступ выдаётся конкретной таблице.

1. Создайте проект в [Google Cloud Console](https://console.cloud.google.com/).
2. Включите [Google Sheets API](https://console.cloud.google.com/apis/library/sheets.googleapis.com).
3. Откройте **IAM & Admin → Service Accounts**, создайте сервисный аккаунт. Проектные роли ему не нужны.
4. В аккаунте откройте **Keys → Add key → Create new key → JSON** и скачайте файл.
5. Сохраните его как `credentials.json` в папке проекта или укажите другой путь при первом запуске.
6. Найдите поле `client_email` внутри JSON. В Google Таблице нажмите **Настройки доступа** и выдайте этому адресу роль **Редактор**.
7. Запустите `python bot.py --google-api` и вставьте ссылку на нужный лист (с `gid`).

Пароль Google в программу вводить не нужно. Если организация запрещает создавать ключи сервисных аккаунтов, используйте OAuth.

#### Вариант 2: ваш Google-аккаунт (OAuth)

1. В [Google Cloud Console](https://console.cloud.google.com/) создайте проект и включите **Google Sheets API**.
2. В **Google Auth Platform** настройте приложение и экран согласия. Для личного приложения в режиме Testing добавьте свой Google-аккаунт в **Audience → Test users**.
3. В разделе **Clients** создайте OAuth Client ID типа **Desktop app**, скачайте JSON и сохраните как `credentials.json`.
4. Запустите `python bot.py --google-api`. Откроется браузер: войдите в аккаунт с правом редактирования таблицы и разрешите работу с Google Таблицами.
5. Токен сохранится локально в `.leetcode-table-bot/authorized_user.json`; следующие запуски используют его повторно.

Приложение запрашивает только scope Google Sheets, без доступа к Google Drive API. OAuth разрешает работу с таблицами вашего аккаунта в пределах этого scope. Сервисный аккаунт ограничен таблицами, которые вы ему открыли.
У тестового OAuth-приложения Google refresh token может истекать через 7 дней. При необходимости повторного входа удалите только `.leetcode-table-bot/authorized_user.json` и запустите программу заново.

Подключение реализовано по [документации gspread](https://docs.gspread.org/en/latest/oauth2.html); ограничения тестового OAuth описаны [Google](https://developers.google.com/identity/protocols/oauth2#expiration).

## Формат вашей таблицы

Бот рассчитан на [ваш шаблон](https://docs.google.com/spreadsheets/d/1_SLnTTen9TJPdMjKD78Pqdh4AzhrBxwVnEjWPTbgPbg/edit#gid=0):

| A: problem number | B: problem name | C: my difficulties | D: link |
| --- | --- | --- | --- |
| 228 | Summary Ranges | Граничные случаи и переполнение | https://leetcode.com/problems/summary-ranges/ |

Заголовки распознаются автоматически, в том числе при другом порядке столбцов и на русском языке.
Если распознать их не удалось, программа попросит указать строку заголовков и буквы столбцов.
В полностью пустом листе появятся эти четыре заголовка. Существующие строки и заголовки программа сохраняет.
Если `gid` отсутствует в ссылке, используется первый лист.

## Как пользоваться

```text
Номер задачи: 228
╭─────────────────────────────────────────────────────────────╮
│ #228  Summary Ranges   Easy                                  │
│ https://leetcode.com/problems/summary-ranges/                │
╰─────────────────────────────────────────────────────────────╯
Что вызвало сложности?
  │ Забыл проверить пустой массив.
  │ При сравнении соседних чисел возможно переполнение.
  │ .
✓ Задача №228 сохранена.
```

Точка **на отдельной строке** завершает заметку. `/skip` сохраняет задачу без заметки, `/cancel` отменяет ввод задачи.
Пустые строки внутри заметки разрешены. Сохранение в Google происходит после ввода заметки, одной строкой.
Название и URL записываются текстом; Google Таблицы обычно автоматически делают URL кликабельным.
Содержимое заметки записывается буквально и не выполняется как формула.

Если номер уже присутствует в журнале, бот предлагает:

- **дополнить** — добавить текст к заметке последней записи этой задачи, сохранив старый текст;
- **новая** — добавить отдельную строку для повторного решения;
- **отмена** — вернуться к вводу номера.

Команды в поле номера:

| Команда | Действие |
| --- | --- |
| `/help` | Подсказка |
| `/config` | Текущая таблица и столбцы |
| `/draft` | Последняя локальная копия задачи и заметки |
| `/exit` или `q` | Выход |

`Ctrl+C` и `Ctrl+D` завершают работу без traceback. Незавершённый ввод заметки при этом отменяется.

## Настройки и восстановление

- `config.json` — URL таблицы, способ подключения, адрес и токен Apps Script (либо путь к JSON-ключу), строка заголовков и номера столбцов (A = 1).
- `config.example.json` — пример настроек под вашу таблицу; настоящий конфиг создаётся при первом запуске.
- `.leetcode-table-bot/leetcode_cache.json` — кеш названий и ссылок задач; обновляется раз в сутки и при поиске отсутствующего номера.
- `.leetcode-table-bot/doocs_index.json` — кеш резервного открытого каталога doocs/leetcode.
- `.leetcode-table-bot/last_entry.json` — последняя задача и заметка; копия создаётся **перед** запросом записи в Google.
- `.leetcode-table-bot/authorized_user.json` — OAuth-токен, если используется вход через браузер.

Если Google вернул ошибку или соединение оборвалось, локальная копия доступна через `/draft`.
Перед повторной отправкой проверьте таблицу: при сетевом тайм-ауте сервер мог уже сохранить строку.
Автоматической повторной записи нет. Копия хранит одну последнюю заметку, а не историю.

При недоступности LeetCode бот использует ранее загруженный кеш. Если задачи в кеше нет, автоматически обращается к открытому каталогу [doocs/leetcode](https://github.com/doocs/leetcode), проверяет номер и берёт точную ссылку из заголовка документа. В интерфейсе показывается источник. После первой ошибки LeetCode повторно не запрашивается в текущем запуске.
Используются только метаданные задачи, без выполнения чужого кода. Каталог doocs распространяется на условиях [CC BY-SA 4.0](https://github.com/doocs/leetcode/blob/main/LICENSE); решение задачи в таблицу не копируется.
Если недоступны оба источника, бот предлагает ввести ссылку и название вручную, после чего сохранение заметки работает как обычно. Вручную введённые метаданные не добавляются в кеш.
Публичный endpoint LeetCode `/api/problems/all/` не имеет гарантии стабильности и может возвращать HTTP 403 или 429. Обновлять Apps Script или менять токен из-за ошибки LeetCode не требуется.
Поддерживаются числовые номера основного каталога; задачи с номерами LCP, LCR и подобными не поддерживаются.

Перенастройка и отдельный конфиг:

```bash
python bot.py --setup
python bot.py --apps-script
python bot.py --google-api
python bot.py --config /path/to/config.json
python -m leetcode_table_bot
```

Относительный путь к JSON-ключу считается от папки выбранного конфига. Кеш, токен и локальная копия также хранятся рядом с ним, в `.leetcode-table-bot/`.
Не публикуйте ключи, токены и личные заметки: эти файлы уже исключены через `.gitignore`.
