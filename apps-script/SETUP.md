# Подключение без JSON-ключа

Вы работаете в Google Таблице и в редакторе Apps Script. Вручную создавать проект в Google Cloud не требуется.
Код Python-бота уже поддерживает этот способ.

## 1. Откройте Apps Script из своей таблицы

Откройте вашу Google Таблицу под аккаунтом владельца или редактора.
В верхнем меню выберите **Расширения → Apps Script** (**Extensions → Apps Script**).

## 2. Вставьте готовый код

Откройте файл `apps-script/Code.gs` в этом проекте. Скопируйте **весь** его текст.
В редакторе Apps Script откройте `Code.gs` («Код.gs»), замените стандартный пример скопированным кодом и сохраните.
Если в таблице уже есть собственные скрипты, добавьте новый файл вместо удаления их кода; функции `setup`, `doGet` и `doPost` не должны повторяться.

## 3. Запустите setup и сохраните токен

В списке функций рядом с кнопкой **Выполнить / Run** выберите **setup**, затем нажмите **Выполнить**.
При первом запуске Google попросит разрешить этому скрипту работу с таблицами вашего аккаунта.
Проверьте, что разрешение выдаётся только что созданному вами скрипту, и подтвердите запрошенный доступ.

После успешного запуска откройте **Журнал выполнения / Execution log**.
Там появится строка:

```text
Токен бота (скопируйте в Python-программу): <ваш токен>
```

Скопируйте только длинный токен после двоеточия. Он содержит **ровно 64 символа: цифры и буквы a–f**. Бот попросит его на последнем шаге.
**ID развёртывания**, который обычно начинается с `AKfy…` и является частью ссылки `/exec`, — это другой идентификатор; в поле токена его вставлять не нужно.
`setup` привязывает скрипт к этой конкретной таблице. Повторный запуск сохраняет прежний токен.

## 4. Разверните веб-приложение

Нажмите **Начать развёртывание / Deploy → Новое развёртывание / New deployment**.
В выборе типа (значок шестерёнки) выберите **Веб-приложение / Web app**.

Укажите:

- **Выполнять от имени / Execute as:** **Я / Me**.
- **У кого есть доступ / Who has access:** **Все / Anyone** — вариант, доступный без входа в Google.

Нажмите **Развернуть / Deploy**. Скопируйте **URL веб-приложения / Web app URL**, заканчивающийся на `/exec`.
Ссылка тестового развёртывания `/dev` для бота не подходит.

Публичным становится адрес обработчика. Чтение и запись требуют секретный токен, а сам скрипт обращается только к таблице, в которой выполнен `setup`.
Настройки общего доступа самой таблицы менять не нужно. Запросы выполняются с правами вашего аккаунта.
Пользователь с токеном и адресом сможет работать с данными подключённой таблицы; храните токен как пароль и не отправляйте его в чат.

Если Google Workspace не предлагает вариант **Anyone**, администратор мог ограничить такие развёртывания. Этот способ тогда не заработает без изменения политики организации; остаётся авторизация Google API через `--google-api`.

## 5. Подключите бота

Из папки проекта выполните:

```bash
.venv/bin/python bot.py --apps-script
```

Программа спросит:

1. **Ссылка на Google Таблицу** — вставьте обычную ссылку на вашу таблицу. Если она уже сохранена, нажмите Enter.
2. **Ссылка Web app URL (…/exec)** — вставьте адрес из шага 4.
3. **Токен из журнала выполнения setup** — вставьте токен из шага 3. Ввод скрыт.

После сообщения «Подключён лист» введите номер задачи, затем заметку. Завершите заметку точкой на отдельной строке.
Следующие запуски — просто `.venv/bin/python bot.py`: ссылка и токен сохраняются локально в `config.json`.

## Если что-то не работает

- **Неверный токен:** выполните `setup`, скопируйте токен из журнала и снова запустите бота с `--apps-script`.
- **HTTP 401 или 403:** откройте **Начать развёртывание → Управление развёртываниями → Изменить** (карандаш). Укажите **Выполнять от имени: Я / Me**, **У кого есть доступ: Все / Anyone** — именно доступ без входа в Google. Нажмите **Развернуть**. Вариант «Все пользователи с аккаунтом Google» для Python-бота не подходит.
- **Вернулась страница вместо JSON:** проверьте ссылку `/exec` и настройки **Me / Anyone**.
- **Другая таблица:** обычная ссылка в конфиге должна вести к таблице, из которой открыт этот Apps Script.
- **Изменили код:** откройте **Deploy → Manage deployments → Edit → New version → Deploy**. Простое сохранение кода не обновляет опубликованную версию.
- **Ошибка записи:** заметка останется в `.leetcode-table-bot/last_entry.json`; команда `/draft` её покажет. Проверьте таблицу перед повтором.

Google описывает [создание скрипта из таблицы](https://developers.google.com/apps-script/guides/bound) и [развёртывание веб-приложения](https://developers.google.com/apps-script/guides/web) в официальной документации.
